# Brightleaf Mesh Router MX3

## Overview
The MX3 is a tri-band Wi-Fi 7 mesh router. A 2-pack covers up to **5,500 sq ft**; a 3-pack covers up to **8,000 sq ft**.

## Specs
- Wi-Fi 7, tri-band (2.4 GHz, 5 GHz, 6 GHz)
- One **10 GbE** WAN port and three 2.5 GbE LAN ports per node
- Supports up to **200** connected devices per system
- Power draw: 18 W typical

## Setup
Setup uses the Brightleaf Connect app. Firmware updates install automatically at 3 AM local time unless disabled.

## Warranty
The MX3 is part of the Brightleaf Pro series.

## Troubleshooting
If a node shows a **solid red** light it has lost the backhaul connection; move it closer to the main node. A **blinking amber** light means a firmware update is in progress; do not unplug it.
